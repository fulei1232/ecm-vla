## 2. 题目、摘要、亮点、关键词

### 2.1 题目备选

1. **HarvestMem: event-centric memory for vision–language–action harvesting robots under foliage occlusion**（初稿 v0.2 采用）
2. Remembering what was picked and what was hidden: event-aware temporal memory for vision–language–action fruit harvesting robots
3. What to remember when fruits hide: physically grounded event memory for vision–language–action harvesting robots

中文：HarvestMem：面向枝叶遮挡的视觉-语言-动作采摘机器人事件中心记忆

### 2.1b 整体立意（v0.2，初稿已按此重写引言/方法/讨论/结论）

- **问题的严峻性（全部有数据）**：被叶子挡住的成熟果在仍挂树的帧里中位 78% 看不见，决策只能靠记忆；均匀记忆在 16 帧预算下漏掉 43% 的已完成采摘，只有 43% 的决策能数清已摘数，作业超过 600 帧后连"最近一次采摘"都在 78% 的决策里丢失；通用记忆基准上去掉记忆成功率 66.7% → 1.7%、预算减半 64.4% → 26.7%（记忆内容是 VLA 能力的一阶因素）。
- **为什么常规办法不够**：加大记忆——预算须随作业时长线性增长、注意力代价平方增长；更好的逐帧感知——看不见被挡的果、把手里的果当新目标（逐帧检测计数正确率仅 62%）；学习型记忆选择——多参数、训练/部署可能不一致、不可审计。
- **核心洞见**：农业操作中任务相关信息不是均匀分布在时间上，而是集中在少数物理交互事件（接近—接触—脱离）；应**按事件而不是按时间索引记忆**。认知科学依据：事件分割与事件边界优先编码（Zacks 2007），情景记忆绑定 what–where–when（Tulving 1972；Clayton & Dickinson 1998）。
- **整体框架 HarvestMem = 空间记忆 + 情景记忆**：SAM-FDM 在可见时为每个果建立三维锚点（where），PEKM 为采摘事件保留接触/脱离关键帧（what & when），两者只通过一个物理标量 d_t 耦合；零额外参数/token/推理开销，训练部署同一函数，可审计。
- **理论支撑（新，E4b）**：均匀记忆对事件的覆盖率 c_U(t) ≈ min(1, (B−1)|S|/t)，按 1/t 衰减；预测与实测误差 ≤ 0.012（B = 8/16/32：0.282/0.270、0.562/0.570、0.882/0.883）。PEKM 对最近 ⌊k/2⌋ 次采摘恒覆盖、与作业时长无关。见 `experiments/exp_coverage_theory.py` → `results/coverage_theory.json`，图 `figures/fig_coverage_theory.png`。
- **四条设计原则**：P1 按事件而非时间索引；P2 事件由物理定义而非学习特征；P3 只改"记什么"，不改"记多少/怎么记"；P4 先记住"在哪"，才能记住"发生了什么"。
- **定位表**（相关工作 2.5）：与无记忆、最近窗口、均匀采样、学习型记忆库对比"远期记忆 / 保住采摘事件 / 固定开销 / 无额外参数 / 训练=部署 / 物理可解释"六项。

### 2.2 方法与基准命名（全文统一）

| 名称 | 指代 |
|---|---|
| **PEKM**（Picking-Event Keyframe Memory） | 本文记忆方法：采摘事件关键帧 + 均匀覆盖的固定预算记忆 |
| **PEKM-S**（soft） | 软版本：按接近度加权的密度采样（注水上限） |
| **HarvestMem-Sim** | 本文基准：FruitCount、FruitOccludedRipe 两个依赖记忆的采摘任务 |

### 2.3 英文摘要草稿（约 250 词）

> Selective fruit harvesting is inherently a long-horizon, partially observable task: ripe fruits are intermittently hidden by foliage moved by wind or by the manipulator, and harvesting quotas require the robot to keep track of how many fruits it has already placed in a container that is often outside the camera view. Vision–language–action (VLA) policies offer a unified way to map camera images and task instructions to robot actions, but their temporal memory is constrained by a fixed token budget and is usually filled by uniformly subsampling past frames, which dilutes the few moments that actually matter. We propose **Picking-Event Keyframe Memory (PEKM)**, a causal, budget-preserving memory selection mechanism that detects picking events from the end-effector-to-fruit distance and reserves memory slots for the contact and detachment keyframes of the most recent events, while the remaining slots keep uniform temporal coverage. The same selection function is used for training and deployment, and the distance signal only chooses frames and never enters the policy input, so PEKM can be added to a pretrained VLA without architectural change. The distance signal is provided by a **SAM-based fruit perception module** that segments fruits, estimates ripeness and localizes them in 3D from RGB-D images. We further introduce **HarvestMem-Sim**, a benchmark with a 7-DoF RealMan RM75-B arm and EG2 gripper featuring wind-induced foliage occlusion and counting tasks, and a phase-aware noise-injection scheme (DART-H) for recovery demonstrations. Picking events are detected with an F1 score of 1.000 on 199 held-out episodes, and a hysteresis variant keeps F1 at 0.999 under 1 cm perception noise. Under a 16-frame budget, uniform subsampling retains keyframes of only 57.0% of completed picks, whereas PEKM retains 99.6%, and PEKM with 8 frames already exceeds uniform memory with 16. Driven only by RGB-D images and proprioception, the SAM-based module localizes fruits with a median error of 0.48 cm, recovers all foliage-occluded ripe fruits through anchors memorized before occlusion, and reproduces the ground-truth picking events exactly (F1 1.000, keyframe recall 1.000). Colour-prompted SAM segments fruits with an instance F1 score of 0.991 and tighter masks than colour thresholding (IoU 0.974 vs 0.945). 【待填：闭环成功率主结果一句话】（正式初稿摘要见 `manuscript/main.tex`，已压到 226 词） The benchmark, code and evaluation protocol are released to support memory-aware harvesting research.

## 3. 论文主线（写作时反复对照）

**一句话问题**：采摘不是单帧任务。果实会被风吹动的枝叶挡住（看不见 ≠ 不存在），配额采摘要知道"已经摘了几个"，而果篮常不在相机视野里——当前画面不足以决策，必须靠记忆。

**为什么现有方法不够**：VLA 的历史记忆受 token 预算限制（本文基座 512 token ≈ 16–32 帧），通常对整段历史**均匀抽帧**。一次采摘中真正关键的时刻（夹爪接触果实、果实脱离枝条）只占几帧，均匀抽帧既可能漏掉，也不知道哪些帧对应"一次完成的采摘"。

**我们的做法**：把农业作业中天然存在的**采摘事件**作为记忆的组织单位——
1. 用感知得到的"末端到最近可摘果实的距离"因果地检测采摘事件；
2. 为最近几次事件保留"接触帧 + 脱离帧"，其余槽位均匀覆盖；
3. 训练与部署用同一个选帧函数，距离只决定选哪些帧、不进入模型输入，因此不改 VLA 结构；
4. 距离由基于 SAM 的果实感知模块给出，形成"感知 → 事件 → 记忆 → 动作"的完整链路；
5. 用分阶段噪声注入的纠偏示范（DART-H）缓解模仿学习的闭环误差累积。

**怎么证明**：自建依赖记忆的采摘基准；事件检测精度与鲁棒性；记忆的信息保留分析；SAM 感知精度；闭环成功率与过程指标；消融（k、预算、半径、硬/软选帧、信号来源、DART）；严格的配对统计与选帧审计。

## 4. 创新点（Contributions，正文 Introduction 末尾列出）

1. **问题与基准（HarvestMem-Sim）**。首次把"枝叶遮挡下的成熟果记忆"和"视野外果篮的配额计数"形式化为依赖记忆的采摘任务，并构建基于 ManiSkill3 的程序化果树仿真：商用 7 轴 RealMan RM75-B + EG2 夹爪、风致叶簇遮挡与夹爪推叶、果柄运动学约束与脱离判定、基于 mplib 的脚本示范器，以及逐帧真值（果实位姿、可见像素、阶段标签）。共 640 条示范（干净训练 200、DART 训练 200、开发 40、验证 200）。
2. **采摘事件关键帧记忆（PEKM）**。以"接近—接触—脱离"为事件单元的因果事件检测和固定预算记忆选择：最近事件的关键帧优先、其余均匀覆盖、预算严格不变；同一函数服务训练与部署；距离只用于选帧，可即插即用地加到预训练 VLA 上。给出硬关键帧版（PEKM）和接近度加权密度版（PEKM-S）。
3. **SAM 驱动的果实距离模块（SAM-FDM）**。颜色先验提示 + SAM 分割 + RGB-D 反投影得到果实三维位置与成熟度；对观察阶段建立的果实"锚点"进行空间记忆，使被遮挡的成熟果在看不见时仍有距离；用"深度空缺 + 夹爪持物"两路证据判断果实已被摘走；配合滞回（hysteresis）事件检测，对噪声、缺测、偏置鲁棒。只用 RGB-D 和本体感知即可逐帧复现真值事件（F1 1.000），并揭示"遮挡前的空间记忆"是遮挡场景下事件记忆成立的前提（E6）。
4. **面向采摘的分阶段 DART（DART-H）**。只在到达、拉拽、搬运阶段注入时间相关的 OU 关节噪声（接近阶段减半，观察/抓取/释放为 0），记录干净规划动作作为纠偏标签，从扰动状态重规划，得到偏离—恢复示范。
5. **严格可复现的评测协议**。运行前封存方案；配对 bootstrap + Holm 校正 + 等效界限；逐决策选帧审计；同进程配对；反事实对照（同采样器无事件 EVU、匹配随机替换 EVR、反事件 EVA）把"事件信息的作用"与"换帧扰动"分开。

### 3 HarvestMem-Sim 基准（约 900 词）

- 3.1 场景生成：果树主干 + 枝条 + 叶片，4–6 个果实（半径 2.5–2.9 cm），高度 0.44–0.64 m、距基座 0.38–0.50 m、方位 ±28°；保证每个果实存在水平接近的 IK 解、接近通道无枝条遮挡、前置相机视线互不遮挡。
- 3.2 机器人与传感：RM75-B（7 轴）+ EG2 夹爪，`pd_joint_pos` 控制；前置相机（256×256，FOV 55°）+ 腕部相机（256×256）；状态 8 维（7 关节 + 手指），动作 8 维（7 关节目标 + 夹爪）。也支持 6 轴 RM65-B。
- 3.3 两个任务（Fig. 2）：
  - **FruitOccludedRipe**：红（熟）绿（生）混挂；30 步观察阶段内第 8–20 步一阵风把两簇叶子吹到两个果实前（至少一个是红果，"被遮挡"不暗示"成熟"）；要求只摘红果。夹爪进入 15 cm 内时叶簇被推开，所以"最后一段接近可见，但找到被挡的果需要记忆"。
  - **FruitCount**：全部红果，要求恰好摘 N 个（N < M，每个 episode 不同）；果篮在前置相机视野外，策略只能靠记忆数自己摘了几个。
- 3.4 物理与判定：果实在被双指连续夹持 2 步前为运动学固定（挂在枝上），之后变为动力学刚体；成功/失败判定（篮中数量、掉落、错摘）。
- 3.5 示范生成：mplib 规划 + 阶段化脚本（observe / reach / approach / grasp / pull / carry / release / settle）；失败尝试丢弃换种子；每帧真值。
- 3.6 数据划分：train / val / test 种子空间分离（基数 100000 / 200000 / 300000）；val 0–49 已用于早期评测，正式评测用 val 50–99；dev 200–219 只作开发门。

### 4 方法（约 2200 词）

#### 4.1 问题形式化

部分可观测 MDP。决策时刻 t，策略输入：当前前置/腕部图像、本体状态 s_t、语言指令 l、记忆 M_t（固定 B 帧，B = 16）。动作块 A_t = π(o_t, s_t, l, M_t)，长度 20，执行前 16 步。记忆选择函数 M_t = S(帧 0..t, 信号 d_0..d_t)，**只能用 t 及之前的信息（因果）**，且 |M_t| = B 恒定。

#### 4.2 基座 VLA

MME-VLA（perceptual frame-sampling + memory-as-modulator）：π0.5 结构，PaliGemma（Gemma-2B）视觉语言骨干 + Gemma-300M 动作专家 + Gemma-150M 记忆专家；SigLIP 冻结编码，每帧 16 token，记忆 512 token 预算；flow matching 动作生成。从 RoboMME 上训练的 79999 步 checkpoint 初始化，换臂微调到 RM75-B。

#### 4.3 事件信号

d_t = 末端（TCP）到最近一个"可摘且仍在树上"的果实中心的距离（FruitCount：所有果；FruitOccludedRipe：红果）。无可摘果时记 10 m（"远"，非未知）。训练用仿真真值；部署由 SAM-FDM 给出（4.6 节），定义相同。

#### 4.4 因果采摘事件检测

- 近：d_t ≤ r；远：d_t > r；未知（缺测）帧沿用上一已知状态——单帧丢失既不开启也不结束事件。
- 事件 = 极大连续"近"段，贡献两个关键帧：
  - **接触帧**：段内第一个与"到目前为止的段内最小距离"相差 ≤ tol 的帧；
  - **脱离帧**：段后第一个"远"帧（果实脱离枝条后不再可摘，距离跳到下一个果实）。
- 参数：r = 0.03 m，tol = 0.005 m（只依据训练集确定，见实验 E2）。
- 部署变体：滞回检测（进入 r、离开 1.5r）+ 最短 3 帧（实验 E3 证明对噪声更鲁棒）。

#### 4.5 PEKM 选帧（算法 1）

```
输入：距离序列 d_0..d_t，预算 B，关键帧上限 k
若 t+1 ≤ B：返回 {0..t}
events ← DetectEvents(d_0..d_t)
keys ← 从最新事件往前，依次取 (接触帧, 脱离帧)，至多 k 个
rest ← {0..t} \ keys
uni ← rest 中等间距取 B − |keys| 帧（含首尾）
返回 sort(keys ∪ uni)
```

性质：(i) 预算恒为 B；(ii) k = 0 时退化为官方均匀抽帧（因此 K0 是严格对照）；(iii) 因果；(iv) 训练每个样本的记忆与部署时完全同一函数计算（train–deploy consistency）；(v) 距离只选帧、不入模型。

PEKM-S（软版本）：密度 ρ_f = (1−α)/N + α·w_f/Σw，w_f = exp(−max(d_f − d₀, 0)/τ)，单帧密度上限 1/|H|（注水法），按累积密度系统抽样；保留锚点帧和最近 4 个槽。

图 4（Fig. 4）：同一 episode 的距离曲线 + 均匀 / PEKM / PEKM-S / 随机的选帧刻度（已有原型图 `results/event_memory_preview/BinFill_ep00_seed7.png`，按采摘任务重画）。

#### 4.6 SAM-FDM：基于 SAM 的果实距离模块

1. **果实提示**：HSV 颜色先验（红/绿两类）+ 连通域得到候选点和框（也可替换为轻量检测器）。
2. **SAM 分割**：以候选框/点作提示，SAM（ViT-B/L/H 比较）输出果实掩码；掩码内平均色相判定成熟度。
3. **三维定位**：掩码像素按深度反投影，取可见表面点中位数，沿视线方向补偿一个果实半径得到球心估计。
4. **锚点空间记忆**：观察阶段（风前）建立每个果实的三维锚点；之后每帧与检测结果关联更新；看不见的果实保留锚点（这就是"记住被挡的成熟果在哪"）；果实位移超过阈值或随夹爪移动则判为已摘，移出可摘集合。
5. **距离与事件**：d̂_t = TCP（正运动学）到最近可摘锚点的距离 → 4.4 节滞回检测 → PEKM 选帧。

写法要点：SAM-FDM 和 PEKM 之间只有一个标量接口 d_t，感知模块可替换（SAM、YOLO-seg、真机深度相机），这是工程上的卖点。

#### 4.7 DART-H 纠偏示范

- 执行时对 7 个关节目标加 OU 噪声（平稳标准差 σ = 0.04 rad，相关时间 τ = 10 步）；阶段系数：reach / pull / carry = 1，approach = 0.5，observe / grasp / release / settle = 0。
- h5 中记录**干净规划动作**作为标签；每段从实际（扰动后）关节状态重规划 → 标签指向回到示范路径的动作。
- σ 选择依据：σ ∈ {0.02, 0.03, 0.04} 标定，σ = 0.04 时 TCP 扰动中位数约 2.5 cm（接近闭环策略的典型偏离量级），示范接受率仍可接受。

#### 4.8 训练细节

12000 步，全局 batch 64，AdamW（梯度裁剪 1.0），500 步线性预热到 2.5e-5、余弦衰减到 2.5e-6，EMA 0.999，视觉编码器冻结，种子 42；归一化统计在本数据集上重算（RM75 关节范围远大于 Panda）；k ∈ {0, 4, 8} 三个臂只差 k。硬件：8 × NVIDIA L20 48 GB，每臂 4 卡 FSDP。

### E3 事件检测对感知误差的鲁棒性 ✅

验证集 199 条，r = 3 cm；每种扰动 5 个随机种子（偏置为确定性）。三种检测器：原始（plain）、5 帧因果中值滤波（median5）、滞回 + 最短 3 帧（hysteresis）。记忆稳定性：每个决策点（每 16 帧）用扰动信号算出的 K4 记忆与用干净信号算出的记忆比较——Jaccard 相似度，以及干净记忆的关键帧在扰动记忆中 ±3 帧内被找回的比例（关键帧召回）。

结论写法：
1. 缺测前向填充的设计使独立缺测（遮挡、检测失败）几乎无害：30% 帧缺测时原始检测器 F1 仍为 1.000。
2. 系统偏置 ±1–2 cm 不影响事件计数——深度相机的标定偏差可容忍。
3. 白噪声是主要威胁：原始检测器在 1 cm 噪声下 F1 降到 0.846（距离在阈值附近抖动产生假事件），计数完全正确率只有 0.37；两种滤波都能修复（F1 0.999，计数正确率 0.99）。2 cm 白噪声下中值滤波略好（0.969 对 0.947）；相关噪声下滞回更好（0.953 对 0.941），且滞回不引入时间延迟，关键帧位置更准（1 cm 白噪声下关键帧召回 0.995 对 0.980）。部署默认采用滞回检测；"中值滤波 + 滞回"的组合可在 E6 中一并测试。
4. 连续长缺测（整段接近被挡）会漏掉事件，是剩余的薄弱点——对应讨论中"前置 + 腕部相机互补"。
5. 给出感知模块的精度要求：使用滞回检测时，距离白噪声 ≤ 1.5 cm（F1 0.987）或相关噪声 ≤ 2 cm（F1 0.953）可保证事件 F1 ≥ 0.95，作为 E6 中 SAM-FDM 的达标线。

1. **均匀抽帧系统性地丢失事件。** 16 帧预算下，均匀记忆只覆盖 57.0% 的已完成采摘，只有 43.1% 的决策点能从记忆中数清已摘个数；连"最近一次采摘"也只有 67.5% 被覆盖。原因是采摘接触段只有十几帧，而 16 帧均匀记忆在 500 帧的 episode 里帧间隔约 30 帧，能否碰上全凭运气（与随机记忆 43.2% 同一量级）。
2. **PEKM 按构造保住最近的事件。** PEKM-4 对最近两次采摘的覆盖率为 100%，整体覆盖率 87.6%；PEKM-8 达到 99.6%，计数可恢复率 99.2%（FruitOccludedRipe 最多 3 次采摘，达到 100%）。
3. **预算效率约 2–4 倍。** PEKM-4 在 8 帧预算下的覆盖率（85.9%）高于均匀记忆在 16 帧下的 57.0%，接近均匀记忆在 32 帧下的 88.3%；PEKM-8 在 16 帧下（99.6%）超过均匀记忆在 32 帧下的水平。对显存和推理延迟受限的田间平台，这意味着可以用更短的记忆窗口获得同等的事件信息。
4. **代价很小。** PEKM 的帧间隔中位数为 17 帧，与均匀记忆的 14 帧接近，即非事件部分的时间分辨率基本不变；硬选择对"倒数第三次及更早"的采摘依赖 k 的大小（k = 4 时 13.6%），这正是 k = 8 的动机。
5. **硬选择与软选择的权衡。** PEKM-S 把更多帧集中到近果段（近果帧占比 0.265，是均匀的 6 倍），对较早事件覆盖更均衡（倒数第二、三次采摘覆盖率接近 1），但最近一次采摘的覆盖率降到约 0.81，帧间隔中位数增加到 63 帧，牺牲了全局上下文。因此正文以硬选择 PEKM 为主方法，PEKM-S 作为可调变体在消融中讨论。
6. 选帧开销：t = 1000 帧时 PEKM 单次选帧 117 µs（中位数，p99 125 µs），均匀抽帧 39 µs，相对 VLA 推理（数百 ms）可忽略（E11）。

### E6 感知 → 距离 → 事件 → 记忆全链路 ✅（`experiments/exp_perception_distance.py` → `results/perception_distance.json`）

用验证集 199 条示范的前置相机 RGB-D（h5 原始记录）和本体感知（TCP 由正运动学、夹爪开度），完全不用仿真真值，重建距离信号 d̂_t，再与真值信号产生的事件和记忆比较。

**SAM-FDM 的三步（方法节 4.x 同步写入）：**

1. **果实锚点（空间记忆）**：在观察阶段第 0 帧（风吹之前）运行 SAM-FDM（ViT-H），每个实例掩码反投影成球心估计（掩码中位表面点沿视线后推一个由面积和深度估计的半径），并由掩码颜色给出成熟度。锚点在整个 episode 中保留。
2. **空缺检测（视觉 + 触觉两路证据）**：每帧把每个未摘锚点投影回图像，取 5×5 邻域深度中位数：比预期果面深 5 cm 以上记为"空"（连续 3 帧确认"已摘"），浅 2 cm 以上记为"被遮挡"（不提供信息，不改变状态）。另一路是夹爪：闭合指令下手指停在空载闭合与全开之间（手里有物体）持续 2 帧，且 TCP 在某锚点 3 cm 内，则该锚点"已摘"。
3. **距离**：d̂_t = TCP 到最近的、未摘的可摘锚点（FruitCount 为全部，FruitOccludedRipe 为判为成熟的）的距离；没有则 10 m。与训练用的真值定义一一对应。

**对照（消融）：**

- 仅深度空缺（去掉夹爪证据）；
- 风后锚点（在第 29 帧、风吹之后建立锚点，即没有"遮挡前的空间记忆"）；
- 逐帧检测（没有锚点记忆：每帧用当前图像的颜色检测反投影，看不见就是未知）；
- 深度噪声（σ(z) = 1 mm + 2.5 mm·z²，2% 缺测，接近消费级 RGB-D 相机）。

4. **锚点记忆比逐帧检测更稳。** 没有锚点时，搬运中的果子（在夹爪里）仍被检测为"最近的果子"，脱离帧误差 52 帧，并产生假事件（原始检测器精确率 0.821）；滞回检测能压掉一部分假事件（0.942），但记忆 Jaccard 仍只有 0.42。

## 8. 可以写进论文的新想法（💡，讨论/未来工作或后续扩展实验）

1. **事件计数提示（symbolic event memory）**：事件检测器顺带得到"已完成采摘数"，以文本形式拼进语言指令（如 "picked 2 of 3"）。基座已有 `TokenizePromptWithSymbolicMemory` 接口，实现成本低，对 FruitCount 是直接的计数记忆。可作为 PEKM 的扩展臂（PEKM + count prompt）。
2. **锚点空间记忆 + 视觉记忆的双通道**：SAM-FDM 的果实锚点本身就是一种显式空间记忆，可与 VLA 的视觉帧记忆互补；讨论"显式（几何）记忆 vs 隐式（视觉帧）记忆"的分工。
3. **视觉事件检测器**：用腕部相机图像直接分类"接触/脱离"（替代距离阈值），去掉对深度的依赖。
4. **风扰与果实摆动**：把风扩展到全程（果实随枝条摆动），考察事件检测与记忆在动态场景中的表现。
5. **主动推叶**：被挡果实的锚点引导夹爪先推开叶簇再观察。
6. **多作物迁移**：番茄串、草莓、柑橘的"接近—作用—离开"事件结构；修剪、疏果、授粉作业。
7. **真机验证**：RealMan RM75-B + EG2 + RealSense，仿真到真机的域随机化（光照、果色、叶片密度）；可作为后续期刊扩展版的核心增量。
8. **学习型记忆管理器**：用反事实教师信号（已有基础设施）训练轻量价值预测器，与 PEKM 的规则式选帧比较。
