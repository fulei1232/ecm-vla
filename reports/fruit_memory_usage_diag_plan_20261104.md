## 1. 事后指标和解释边界

- hidden由layout.occluders的fruit编号标记，成熟/未成熟都保留。
- 接近按TCP到仍挂树果实中心<15cm计算，包含首次脱果帧；不把搬运中TCP接近已摘果当作查看。另列按环境真实移动叶簇中心计算的PUSH_START触发，二者不混同。
- omission_hidden_ripe：至少一颗被遮挡的成熟目标，结束时从未进入15cm范围。另列果实分母、每颗接近及脱果时间。
- checked_hidden_unripe：至少一颗被遮挡的未成熟果实曾进入15cm范围，且整回合未脱果；同时报告全部回合分母和有被遮挡未成熟果实的可用回合分母。这里“未抓取”只代表没有连续抓握导致的成功脱果，不能排除短暂触碰或单步抓握，几何接近也不等于有意查看。
- 错果采用D5 commission口径：未成熟果实脱果或错误入篮；分别列hidden/visible未成熟果实和仅wrong_in_basket的回合数。
- §14.5的“遗漏加错果合计”为两个回合指示变量之和：I(any omission)+I(any commission)，单回合可贡献2。另列两者并集和仅错误入篮的指标，不用它们替换主判定。
- pre_gust_retained按实际物理控制步<8计算，不用策略相对时钟。物理步0对应策略时钟−30；第一个策略决策在物理步30。按已脱离成熟目标数分为第1/2/3颗之前，目标已摘尽单列；搬运中已脱离的果实计入已处理。
- 专家对照包括100条干净和100条DART遮挡训练示范，分开报告。既报告同一几何接近代理，也报告专家明确reach目标和首次接近时的计划target；专家路过未成熟邻居不能解释为主动查看。训练与D5布局不配对，只做描述。
- 计数掉果阶段是观察性代理：首次脱果后，果实与TCP间距首次>8cm；之前出现张开指令归释放，否则2步内失手归抓取，失手前TCP相对脱果点移动≤5cm归拉拽，其余归搬运。另保存脱果、张开、失去接近和触地失败的步数，不把落地检测时刻冒充失手原因。按果实事件统计并同时列失败回合数。
- 超时末200步报告关节目标变化>.005rad比例、张开比例、4cm持果比例、TCP路程/净位移和末态。运动步比例≥5%标为持续运动，否则分持果停滞、放下后停滞和空夹爪停滞。仅作描述。
- 所有配对区间按布局聚类bootstrap10000次，保留每布局的全部模型种子，固定基础种子20261104并按指标名称SHA256分子流；不进入D5的Holm族。

## 4. 预先指定的A/B/C规则

只用遮挡任务的K0_no_pregust对K0_normal，合并40布局×2种子=80条：
成功率下降=normal成功率−no_pregust成功率；错误上升=no_pregust的遗漏+commission均分−normal均分。用有符号差，不取绝对值。

- A：任一退化≥10个百分点；
- B：两项退化都严格<5个百分点；
- C：其余情况。

整数计数比较门槛，避免浮点误差：A为80条中至少损失8个成功或增加8分错误；B为两项各少于4。区间只报告，不加入显著性门槛或改判。
计数recent16仅作参照；所有成功率、掉果阶段和超时末段均列出。即使退化，也不能直接解释成计数记忆，因为历史可影响控制状态/输入分布。
不完整或审计无效的数据不伪装成C；交付已完成部分和阻塞原因。
