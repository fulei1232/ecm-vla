# 事件记忆反事实消融：真值距离下的闭环检验（2026-10-25）

状态：方案，运行前封存。只使用 val split；V-A 结果目录只读。本方案在看到任何事件记忆闭环结果之前写定。

## 1. 目的

- 事件记忆的思路：按机械臂末端到目标抓取位姿的距离重新分配记忆槽位，越近保留的帧越多，同时混合均匀保存。
- 感知模块尚未接入。本次用仿真器的真值距离代替它，这是特权信号。本次回答两个问题：
  1. 如果距离信号完全准确，按它重新分配历史槽位，冻结策略的成功率会不会高于官方均匀选帧？
  2. 如果有收益，它来自距离信息本身，还是来自换帧带来的扰动？
- 结论只适用于"准确距离信号"这个上限。接入感知模块后的版本另立方案。

## 2. 范围

- 任务：PatternLock、BinFill、VideoUnmaskSwap。
- episode：val 0–19；模型种子 7、8、9；共 180 组（任务 × episode × 种子）。
- checkpoint、策略配置、执行步长（16）、步数上限（1300）都与 V-A 相同。记忆预算为官方的 32 帧。
- 只有闭环条件：不跑专家、不打分，服务器不加载 FP32 老师。

## 3. 距离信号与接近度

每一帧 f 的距离 d_f（米）由该帧的仿真器真值算出（`event_memory.gt_distance`，读取客户端写入的 `raw_frames.jsonl`）：

| 任务 | 目标 | 距离 |
|---|---|---|
| PatternLock | 本 episode 选中的按钮 | TCP 到最近一个按钮的水平（XY）距离。按压棒挂在 TCP 下方约 6 cm，三维距离到不了 0 |
| BinFill | 任务语言中要求颜色的方块 | TCP 到最近一个的三维距离 |
| VideoUnmaskSwap | 场景中生成的箱子 | TCP 到最近一个的三维距离 |

- 水平坐标绝对值 ≥ 2 m 的物体视为不在桌面上，不参与计算。没有 TCP 或目标时，距离为未知。
- 接近度：p_f = exp(−max(d_f − d₀, 0)/τ)。d₀ = 0；距离未知时 p_f = 0。
- τ 按任务的几何尺度确定：
  - PatternLock：τ = 0.01 m。按钮间距约 10 cm，取 5 cm 时几乎每一帧都在某个按钮附近，接近度没有区分度。
  - BinFill：τ = 0.05 m，约为方块和夹爪的尺度。
  - VideoUnmaskSwap：τ = 0.05 m。
- 确定 τ 时，只看过记忆消融 U0 录像中三个 episode（各任务 ep0、种子 7）的距离曲线（`scripts/preview_event_memory.py`），没有看任何事件记忆的闭环结果。
- 距离只用来决定选哪些帧，不进入模型输入。每个决策只用到当前帧及之前的帧。

## 4. 条件

划分沿用 `partition.py`：决策时刻最新帧为 F，官方选帧为 U，锚点 A = U[:1]，历史 H = U[1:-4]（满时 27 个槽），近期 R = U[-4:]。

事件记忆保留 A 和 R，从帧 1 到 R[0]−1 中重新挑选 |H| 个历史帧（`event_memory.event_selection`）：

1. 每帧的密度 ρ_f = (1−α)/N + α·w_f/Σw，其中 N 为可选帧数，w 为该条件的权重，α = 0.5。
2. 每帧密度的上限为 1/|H|，超出部分按比例分给其余帧（注水法），这样一段很近的时段不会占满所有槽位。
3. 按累积密度在 (i+½)/|H|（i = 0…|H|−1）处等间隔抽帧（系统抽样），抽出的帧互不重复。

U 未满 32 帧、或 Σw = 0 时，记忆就是 U。

| 条件 | 记忆 |
|---|---|
| U0 | 官方 U |
| EV | 事件记忆：w = p，α = 0.5 |
| EVU | 同一采样器，w ≡ 1、α = 1，即均匀密度，不含距离信息 |
| EVR | 与 EV 换掉同样多的 U 帧（换掉的就是 EV 换掉的那些），换入帧从不在 U 中的可选帧里随机抽取；种子由（任务、episode、模型种子、决策序号）决定 |
| EVA | 反事件：距离已知的帧 w = 1 − p，未知的帧 w = 0，α = 0.5 |

- 对照 EVU 最关键。EV 每个决策会比 U 多换十几到二十几帧，其中一部分只是采样器的取整位置不同。EVU 用同一个采样器、同样的步骤，只是不看距离，所以 EV − EVU 才是距离信息本身的作用。
- 记忆不跨决策累积：每个决策都从当前的 U 和距离重新计算。
- 每个决策的距离序列写入 `event_signal.jsonl`，所选帧和换帧统计写入 `oracle_decisions.jsonl`。
- 每组的五个条件在同一个服务器进程内完成，顺序按固定种子 20261024 随机。环境种子相同，每个 episode 开始时策略 RNG 都重置。

## 6. 统计

- 主对比（一族，6 项 Holm 校正）：每个任务分别计算 E1 = EV − U0、E2 = EV − EVU。
- 次要对比（单独一族，6 项 Holm 校正，不改变判定）：每个任务分别计算 E3 = EV − EVR、E4 = EVA − U0。
- 方法：按 episode 重抽样、保留同一 episode 全部种子的配对 bootstrap，20000 次（种子 20261024）；α = 0.05；界限 δ = 12 个百分点。

## 7. 判定规则（每个任务分别判定）

- E1 提升且 E2 提升：**事件记忆优于官方选择，也优于同一采样器的无事件版本**。准确的距离信号对记忆选择有用，值得接入感知模块再检验。
- 只有 E1 提升：**优于官方选择，但不优于无事件版本，收益不能归因于事件信号**。
- E1 退化：**事件记忆差于官方选择**。
- E1 小于界限：**没有可见提升**。
- 其他：**未定**。不自动加种子；任何扩展都另立方案。
